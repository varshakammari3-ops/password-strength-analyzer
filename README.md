# Password Strength Analyzer 🔐

A simple Python-based cybersecurity project that analyzes the basic strength characteristics of a password.

## Features

- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Gives a basic password strength result

## Technologies Used

- Python
- VS Code

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
